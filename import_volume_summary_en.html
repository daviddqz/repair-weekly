Methodology
1. Import volume = VD(MTY) + ID-MT movements at the same SMD location, SOC = Exclude, same period as the estimate report (2026-10-10 to 2026-11-09).
2. Of the 50 location codes supplied, THSCS is not a standalone SMD in the system table (it belongs to THBKK) and is therefore merged into THBKK rather than double counted; among the remaining 49 locations, 49 returned valid data and locations without data are left blank, not 0.
3. Repair volume (11,648 boxes, of which open 1,633) comes from Manage Repair three-status details for the same query period, by Office; this table is by SMD location, a different classification, so the ratios are only an order-of-magnitude reference. Empty results are never counted as 0.
