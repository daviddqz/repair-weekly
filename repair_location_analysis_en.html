Of the full SBI fleet of 28,329 units, 6,667 remain after filtering by container-number prefix (BXAU / SLVU / VOTU / VOLU / BAXU); this table lists only MT / ID / IC, totalling 4,350 units, across 66 locations (Location = the first 5 characters of Movement Yard, counted on all movements; locations with no MT / ID / IC units are not listed). Data as of 2026-10-28.
Locations: 66 (prefix fleet 4,350 units · prefix change 4,662 units)

Scope of the two lists not interchangeable

The left half (columns MT / ID / IC + total) = prefix-filtered fleet units on hand (Lease Term = SBI, filtered by container-number prefix; other movements are no longer listed, so the total is smaller than the full filtered fleet); the right half = prefix changes completed (from the WeCom doc "Change container's cost"; Date of Change is a date = completed; text such as "in progress" or blank = not done, excluded). The two are independent: prefix-change units are not a subset of the prefix fleet, so "Change / units" is only an order-of-magnitude reference. Cost follows the sheet's column K (Currency); anything unlabeled is treated as USD. Rows show the local-currency amounts per currency and cannot be added across currencies; a separate Cost (USD) column converts them at the day's FX rate, and the total row is given in USD.
